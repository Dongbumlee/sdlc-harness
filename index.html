01 / SYSTEM

One front door.
A full engineering bench.

Talk to one Harness agent. It identifies the SDLC phase, verifies prerequisites, delegates to the right specialist, and keeps quality gates in the path to release.

ORCHESTRATED BY DESIGN

Analysis, scaffolding, implementation, documentation, responsible AI review, and release each have a defined owner with scoped tool access.

  • Least-privilege agent roles
  • Explicit phase routing
  • Visible subagent work
  • Validation before handoff

04 / ADVERSARIAL QA

A review engine that is allowed to say no.

Independent contexts, anti-leniency instructions, numeric scoring, and hard failure rules turn review from a polite ritual into an evidence gate.

QUALITY GATEPASS ≥ 7.0
Architecture≥ 7

Deployment≥ 7

Find. Fix. Re-review the part that failed.

Nine reviewers work in parallel without seeing one another's findings. If a domain misses its threshold, Harness routes targeted fixes and re-runs the failing review—up to three rounds.

01

Independent contexts

Reviewers do not inherit the generator's rationale or anchor on one another's verdicts.

02

Hard-fail thresholds

Security below 8, composite below 7, or any Critical finding stops the release.

03

Structured output

Scores, severity, location, recommendation, and reasoning arrive as machine-readable YAML.

weighted composite = (security × 1.5 + sum of other reviewers) / 8.5
05 / QUICK START

Install once.
Bring the whole system.

Use the Agent Plugin in VS Code or GitHub Copilot CLI. Then open a project and ask Harness to initialize the workspace.

  • VS Code + GitHub Copilot Chat
  • Python 3.12+ and uv
  • Git 2.40+ and Docker
  • Azure tooling when using the included Azure Pack
# Register the marketplace once $ copilot plugin marketplace add Dongbumlee/sdlc-harness # Install the plugin $ copilot plugin install sdlc-harness@sdlc-harness
# Open your project, then start Harness /agent harness initialize workspace # Harness deploys MCP config, quality instructions, # and prompt files, then asks for project details.

VS Code requires defaultApproval: autopilot and virtualTools.threshold: 0. Start MCP servers, then open a new Chat session so tools are registered.
