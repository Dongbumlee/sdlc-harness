# Code of Conduct

This project is a working space. Keep it one.

## Expected

- Critique code, designs, and decisions — never people.
- State disagreements with evidence; once a decision is recorded,
  accept it and move on.
- Assume good faith until a pattern proves otherwise.
- Keep threads on topic and in the open, so the next reader learns too.

## Not accepted

- Harassment, personal attacks, or discriminatory language.
- Publishing another person's private information.
- Sustained disruption of issues, reviews, or discussions.

## Enforcement

Maintainers may edit or remove comments, close threads, and block
accounts that break these rules. Report problems privately to the
maintainers through the repository owner's GitHub profile; reports
are handled confidentially.
